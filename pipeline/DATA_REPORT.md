## methods

- **Heights**: OSM `height` (via Overture) > OSM `building:levels` x 3.3 m > Google Open Buildings 2.5D 2023 max height inside the footprint (0.5 m raster; values cap at 98 m, so the tallest towers read low) > default = median Open Buildings height of footprints in the same area bin.
- **Open Buildings vs OSM-tagged heights** (footprints > 150 m2 with both): {'n': 166, 'corr': 0.918, 'medianAbsErrM': 5.7, 'medianBiasM': -1.8}.
- **Default heights by footprint bin (m2 -> m)**: {'0-40': 5.5, '40-80': 6.0, '80-150': 6.8, '150-300': 7.5, '300-600': 9.0, '600-1200': 12.5, '1200-2500': 15.5, '2500-1e+12': 21.0}.
- **Footprints** < 12 m2 dropped; multipolygons split; outer rings only; simplified 0.2 m; coordinates quantised to 1e-6 degrees (~0.1 m).
- **Road widths**: OSM car ways; every 8 m an 80-100 m cross-section is cut by the BMA right-of-way polygon containing the point. Ways with < 3 samples get no width (mostly private sois and service roads absent from the public-way layer). Junction samples read long; use `p10`/`med`.
- **Gazetteer**: {'zone': 31, 'road': 496, 'soi': 2538, 'station': 124}; stations by system {'BTS': 39, 'SRT': 28, 'MRT': 41, 'ARL': 4, 'BRT': 12}. Stations under construction (OSM `construction:railway`) excluded.
- **Known gaps**: Overture/OSM footprints miss some new towers; Open Buildings is 2023 imagery; the existing building on a user's plot is removed at runtime by `src/site/`.
